# 📘 Assignment: Hangman Game Challenge

## 🎯 Objective

Create a playable Hangman game in Python that uses loops, conditionals, and string handling to track a hidden word and respond to player guesses.

## 📝 Tasks

### 🛠️ Guessing the Word

#### Description
Write a Python program that lets a player guess letters in a hidden word and shows progress after each guess.

#### Requirements
Completed program should:

- Choose a random word from a predefined list
- Display the current word state using underscores or blanks for unguessed letters
- Accept a single letter guess from the player
- Reveal correctly guessed letters in the hidden word
- Tell the player when a letter has already been guessed
- Track remaining attempts or lives
- End the game with a win or loss message

### 🛠️ Game Flow and Feedback

#### Description
Improve the game experience by adding clear feedback and reliable game-ending logic.

#### Requirements
Completed program should:

- Show the player's remaining attempts after each incorrect guess
- Prevent invalid input such as empty or multi-letter entries
- End the game when the word is fully guessed
- End the game when the player runs out of attempts
- Display a final message that tells the player whether they won or lost
